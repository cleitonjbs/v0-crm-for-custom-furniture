COMO USAR
================================================================================

1. INSTALAR
   $ npm install

2. CONFIGURAR
   $ echo "DATABASE_URL=postgresql://..." > .env.local

3. RODAR
   $ npm run dev
   
4. ACESSAR
   → http://localhost:3000
